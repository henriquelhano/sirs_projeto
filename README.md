# SIRS Project

Project developed as part of the **Network and Computer Security** course, with the goal of applying the knowledge acquired throughout the course by implementing a complete secure network solution.

## 📋 About the Project

This repository contains the project developed for the SIRS course.

The main goal of the project is to configurate a secure network for the RedVector Enterprise.

## 📚 Academic Context

This project was developed as part of the **SIRS** course.

The main objective was to put into practice the concepts and techniques covered throughout the course while developing a functional solution according to the project's requirements.
